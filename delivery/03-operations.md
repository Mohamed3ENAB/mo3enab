## ٣. النقدية — أكتر حتة بتضيع فيها الفلوس

### العهدة المركزية
مبلغ **٣٬٠٠٠–٥٬٠٠٠ ج** عندك للمشتريات. السائق ياخد الفلوس **منك** قبل ما يتحرك، مش من جيبه ولا من العميل مقدمًا.

**ليه ده مهم؟** (١) السائق ما بيرفضش الطلبات الكبيرة، (٢) العميل مش متطلّب منه ثقة مقدمًا، (٣) وده أقوى سبب يخلي السائق محتاجك — لو العميل كلمه مباشرة، هيدفع من جيبه. راجع "المشكلة رقم ١" في `README.md`.

### معادلات التسوية اليومية

```
المطلوب من السائق = (ثمن البضاعة المحصَّل) + (أجرة التوصيل) − (حصة السائق) − (اللي صرفه من العهدة)
الفرق = المتوقع − المسلَّم        ← لازم يساوي صفر
```

### القواعد
1. التسوية **يومية** مش أسبوعية. التأخير بيخلي الفرق مستحيل تتبعه.
2. كل إيصال شراء **يتصوّر**. مفيش استثناء.
3. فرق نقدي مرة → مراجعة. **مرتين → تجميد** لحد ما يتحل.
4. ثمن البضاعة **منفصل** عن الأجرة في كل شاشة وتقرير.
5. السائق ما يحملش أكتر من ١٥٠٠ ج نقدًا في أي وقت.

## ٤. الإسناد

- الطلب المحلي → أقرب سائقين متاحين، **٦٠ ثانية** للقبول، وبعدها لسائق تاني.
- طلبات المحلة أو قيمة عالية → **إسناد يدوي** لسائق معتمد بسقف أعلى.
- مفيش سائق؟ → اعرض **وقت بديل** أو المشوار المجدول الجاي. **متسيبش الطلب معلق.**
- 🔴 في الطيار، بلّغ السائق بـ**مكالمة أو واتساب** مش إشعار تطبيق. إشعار PWA على أندرويد رخيص ممكن يتأخر أو ميوصلش — والطلب بيموت.

## ٥. الطلب المتعثر

| الحالة | التصرف |
|---|---|
| المحل مش بيرد | اتصالين خلال ٥ دقايق → اسأل العميل على بديل |
| السعر الفعلي أعلى | 🔴 السائق **ما يشتريش** قبل موافقة العميل |
| العميل مش بيرد | استنى ١٠ دقايق → اتصال من الإدارة → رسوم إلغاء لو استحقت |
| الغرض مختلف عن الوصف | أوقف · صوّر · قرار الإدارة |
| حادث أو عطل | 🔴 **سلامة السائق الأول** → بديل → وثّق الواقعة |
| فرق نقدي | جمّد التسوية · راجع الإيصال · شوف سجل السائق |

## ٦. المؤشرات — راجعها كل يوم قبل ما تقفل

| المؤشر | الهدف | لو ساء |
|---|---|---|
| معدل قبول الطلب | > ٨٠٪ | راجع الأجرة والمناوبات |
| زمن الإسناد | < ٥ دقايق | زوّد السائقين المتاحين |
| زمن التوصيل | حسب النوع | افصل انتظار المحل عن الطريق |
| الإلغاء | < ١٠٪ | صنّف السبب — النسبة لوحدها متقولش حاجة |
| **إعادة الطلب خلال ٣٠ يوم** | > ٣٠٪ | 🔴 أهم مؤشر عندك |
| **طلبوا مرة واحدة بس** | < ٥٠٪ | 🔴 فوقها = الناس بتلتف حواليك |
| الفرق النقدي | صفر | تسوية يومية + تجميد عند التكرار |

## ٧. معيار الاستمرار أو التوقف — بعد أول ١٠٠ طلب

| النتيجة | القرار |
|---|---|
| ≥ ٣٠٪ أعادوا الطلب + مفيش خسائر نقدية متكررة | ✅ كمّل وابني ميزات المتاجر والدفع |
| الطلب موجود بس التسليم متأخر | ⚠️ عالج المناوبات والإسناد **قبل** أي تسويق |
| معظم الطلبات مشاوير محلة | 🔄 خصّص المنتج للحالة دي — ده منتج أبسط وأربح |
| الإلغاء عالي بسبب السعر | 🔄 جرّب التجميع، **متخفضش السعر عشوائيًا** |
| < ١٠٪ يعيدوا الطلب | 🛑 **أوقف التوسع.** افهم المشكلة قبل أي برمجة زيادة |
