# المواصفة — دليل السواقين المتاحين

المنتج كله ٥ شاشات. لو لقيت نفسك بتبني شاشة سادسة، ارجع للـ`README.md`.

---

## ١. الشاشة الرئيسية — الدليل

**دي الشاشة اللي كل حاجة بتتبني حواليها.** الهدف: حد يفتح اللينك وفي **أقل من ٥ ثواني** يعرف مين متاح ويضغط اتصال.

```
┌──────────────────────────────────┐
│  في السكة · القيصرية        ▾   │   ← اختيار القرية
├──────────────────────────────────┤
│ [الكل] [دليفري] [توك توك]        │   ← فلتر الخدمة
│ [بضاعة] [عجلة] [مشوار المحلة]    │
├──────────────────────────────────┤
│ 🟢 متاح دلوقتي (٣)               │
│ ┌──────────────────────────────┐ │
│ │ محمد ع.            ✅ موثّق  │ │
│ │ موتوسيكل · دليفري · بضاعة    │ │
│ │ 🟢 حدّث من ١٢ دقيقة          │ │
│ │ ⭐ ٤.٦ (١٨)                  │ │
│ │  [📞 اتصال]  [💬 واتساب]     │ │
│ └──────────────────────────────┘ │
│           ...                     │
├──────────────────────────────────┤
│ ⚪ مش متاح دلوقتي (٧)      ▾    │   ← مطوية
└──────────────────────────────────┘
```

**قواعد العرض:**

| القاعدة | السبب |
|---|---|
| المتاحين الأول، والباقي في قسم مطوي | الناس بتفتح عشان تلاقي حد **دلوقتي** |
| 🔴 اكتب **«حدّث من X دقيقة»** مش «متاح» بس | الصدق بيبني الثقة. «متاح» المجردة بتكدب لما السائق ينسى |
| 🔴 التوفر بينتهي تلقائيًا بعد ٤ ساعات | القايمة الكذابة بتقتل التطبيق أسرع من القايمة الفاضية |
| الموثّق فوق غير الموثّق | دي قيمتك الحقيقية: إنك شفت البطاقة بنفسك |
| زر الاتصال كبير وواضح | معظم الناس هتستخدمه وخلاص |
| ✅ يشتغل من غير تسجيل | أي حد يفتح اللينك ويستخدم على طول |
| يشتغل على نت ضعيف | صفحة خفيفة · من غير خرايط · صور قليلة |

## ٢. صفحة السائق (اختيارية)

اسم · نوع المركبة · القرية · الخدمات · شارة موثّق · تقييم · ملاحظة («بشتغل من ٢ لـ ١٠») · زر اتصال · **زر بلاغ صغير**.

---

## ٣. لينك السائق الخاص — بدل كلمة السر

كل سائق بياخد لينك زي `/d/a3f9c2...` — يحفظه على شاشة موبايله. يفتحه فيلاقي:

```
┌──────────────────────────────┐
│  أهلاً محمد                  │
│                              │
│   ┌──────────────────────┐   │
│   │   🟢  أنا متاح       │   │   ← زرار واحد كبير
│   └──────────────────────┘   │
│                              │
│  آخر تحديث: من ١٢ دقيقة      │
│  هيتقفل لوحده بعد ٤ ساعات    │
└──────────────────────────────┘
```

**ليه كده مش كلمة سر؟** مفيش تسجيل، مفيش رسايل SMS (أكبر تكلفة شهرية)، ومفيش سائق بينسى كلمة سره. زرار واحد بس.

⚠️ اللينك ده سر — زي كلمة السر. ابعته لكل سائق **في رسالة خاصة**، مش في جروب.

## ٤. لوحة الطلبات المفتوحة

حد محتاج حاجة ومش عارف يكلم مين؟ يكتب طلب، وكل السواقين يشوفوه ويكلموه.

```
┌──────────────────────────────────┐
│  اكتب طلبك                       │
│  ┌────────────────────────────┐  │
│  │ محتاج حد يجيبلي دوا من     │  │
│  │ المحلة النهاردة            │  │
│  └────────────────────────────┘  │
│  تليفونك: [__________]           │
│  [ انشر الطلب ]                  │
└──────────────────────────────────┘
```

**قواعد:** الطلب بيختفي تلقائيًا بعد **٦ ساعات** · الإدارة تقدر تخفي أي طلب مسيء · **مفيش إسناد ولا متابعة** — دي لوحة إعلانات مش نظام طلبات.

---

## ٥. لوحة الإدارة (ليك أنت)

أبسط حاجة ممكنة، بكلمة سر:

- ➕ إضافة سائق: الاسم · التليفون · القرية · الخدمات · نوع المركبة
- ✅ توثيق (بعد ما تشوف البطاقة والرخصة بنفسك)
- 🔗 توليد لينكه الخاص ونسخه
- ⏸️ إيقاف سائق
- 🚩 مراجعة البلاغات
- 👁️ إخفاء طلب مسيء من اللوحة
- 💰 تعديل الأسعار الاسترشادية

---

## ٦. قواعد العمل

1. **الدليل بيتقرا من غير تسجيل.** أي حد يفتح اللينك.
2. **التوفر بينتهي بعد ٤ ساعات** من آخر تحديث. مفيش استثناء.
3. **لينكات السواقين متقراش من العامة** — لا في الصفحة ولا في الـAPI.
4. **البلاغات سرية** — ليك أنت بس.
5. **السائق الموقوف بيختفي فورًا** من الدليل.
6. **مفيش بيانات عملاء** إلا تليفون في طلب اللوحة، وبيتمسح بعد ٦ ساعات.
7. **الأسعار استرشادية** ومكتوب عليها كده — مش تسعيرة ملزمة.
8. **إخلاء المسؤولية ظاهر** في الصفحة الرئيسية.

## ٧. قاعدة البيانات — ٩ جداول

| الجدول | الغرض |
|---|---|
| `service_zones` | القرى الخمسة |
| `providers` | السواقين: الاسم · التليفون · الخدمات · موثّق · متاح |
| `provider_tokens` | 🔴 اللينك الخاص — **مفصول عن `providers` عشان ما يتقراش مع البيانات العامة** |
| `availability_log` | سجل التوفر — يوريك مين بيشتغل فعلاً |
| `requests` | لوحة الطلبات (بتنتهي بعد ٦ ساعات) |
| `ratings` | تقييم بسيط |
| `reports` | 🔴 بلاغات — للإدارة بس |
| `price_guide` | أسعار استرشادية |
| `admins` | أنت |

+ عرض `providers_public` (الأعمدة الآمنة بدون توكن) + دالة `toggle_availability(token, bool)`.

## ٨. التقنية

| الطبقة | الاختيار | السبب |
|---|---|---|
| الواجهة | PWA عربي RTL — Next.js أو حتى HTML بسيط | لينك واحد · مفيش متجر تطبيقات · تحديث فوري |
| قاعدة البيانات | PostgreSQL عبر Supabase | الحد المجاني كفاية أضعاف حجمك |
| تسجيل الدخول | ❌ مفيش للعملاء · لينك سري للسواقين · كلمة سر ليك | صفر تكلفة رسايل |
| الخرائط | ❌ **متستخدمهاش** | العلامة المميزة والتليفون بيكفوا في البلد |
| الإشعارات | ❌ مفيش | الاتصال المباشر أسرع وأوثق |

> المنتج ده ممكن يتعمل **صفحة HTML واحدة** بتقرا من Supabase. متعقّدش الموضوع.
