# مواصفة المنتج — النسخة الأولى

الملف ده هو المرجع اللي بتدي منه للـAI وأنت بتبني. كل قاعدة هنا مكتوبة بحيث تتحول لكود مباشرة.

---

## ١. الأدوار

| الدور | بيدخل إزاي | بيشوف إيه |
|---|---|---|
| **عميل** | رقم تليفون + OTP | طلباته هو بس · السائق المعيَّن بعد الإسناد · الدعم |
| **سائق** | حساب تنشئه الإدارة بعد مراجعة المستندات | الطلب المسنَد له هو بس · مستحقاته · عهدته |
| **إدارة** | إيميل + كلمة سر + **تحقق بخطوتين إجباري** | كل حاجة |
| **متجر** (مرحلة ٢) | رقم تليفون + OTP | طلباته · قائمته · تسوياته |

**قاعدة صارمة:** الصلاحيات دي تتطبّق على مستوى **قاعدة البيانات** (RLS) مش في الواجهة بس. لو حد فتح الكونسول في المتصفح، ما يقدرش يشوف ولا يعدّل حاجة مش بتاعته. الاختبار ده جزء من معيار قبول كل تذكرة.

---

## ٢. الخدمات الأربعة

### أ) اطلب من محل
العميل يكتب اسم المحل والطلبات، أو **يبعت صورة** للقائمة، أو **رسالة صوتية**.
> الصوت والصورة مش رفاهية — دول أهم من الكتالوج في قرية فيها ناس كبيرة في السن أو مش بتحب تكتب.

- المحل **مش محتاج** حساب في النسخة الأولى.
- السائق يصوّر الإيصال إجباريًا.
- أي زيادة في السعر الفعلي **توقف الطلب** لحد ما العميل يوافق داخل التطبيق.

### ب) أرسل / استلم غرض
نقطة استلام + نقطة تسليم + وصف + قيمة تقريبية + اسم ورقم المستلم.

**ممنوع في النسخة الأولى:** نقدية · ذهب ومجوهرات · أسلحة · مخدرات · مواد خطرة · أدوية بوصفة أو محتاجة تبريد · حيوانات · أي طرد مقفول المرسِل بيرفض يوصف محتواه.

### ج) مشوار المحلة الكبرى ⭐
**مجدول** — مشوارين في اليوم (١١ص و٥م)، إقفال الطلب قبلها بساعة. تفاصيل التصميم والسبب في `02-pricing-economics.md`.
خيار **فوري** متاح بسعر أعلى معلن.

### د) توصيل محافظات
**نموذج طلب تسعير، مش طلب فوري.** المحافظة + العنوان + نوع الغرض + القيمة + الموعد → الإدارة تراجع وتبعت سعر ومدة وشروط **مكتوبة**، والعميل يوافق داخل التطبيق.
> ❌ ممنوع الاتفاق الحر بين العميل والسائق. ده مصدر النزاعات رقم ١ وأنت اللي هتتحمله.

## ٣. نظام العناوين — أهم جزء وأكتر جزء بيتعمل غلط

في القرى مفيش أسماء شوارع ولا أرقام عمارات. دبوس الخريطة لوحده **مش كفاية** — الدقة ضعيفة والسائق هيتوه.

**العنوان الصحيح = ٦ حاجات مع بعض:**

| العنصر | إجباري؟ | مثال |
|---|---|---|
| القرية | ✅ | القيصرية |
| وصف مكتوب | ✅ | «شارع الجامع الكبير، ثالث بيت على الشمال» |
| **علامة مميزة** | ✅ | «قدام صيدلية النور» |
| دبوس خريطة | اختياري | إحداثيات |
| رقم تليفون للمكان | ✅ | ممكن يكون غير رقم الحساب |
| ملحوظة للسائق | اختياري | «الجرس مش شغال، كلمني» |

**قواعد:**
- العنوان يتحفظ ويتعاد استخدامه — العميل ما يكتبوش تاني.
- الإدارة تقدر **تصحّح** أي عنوان يدويًا.
- عنوان برة النطاق → النظام **ما يرفضوش**، يحوّله لـ"طلب تسعير يدوي".
- الملاحة تتفتح **برة التطبيق** (خرائط جوجل) — يوفر تكلفة API كبيرة.

## ٤. حالات الطلب

```
مسودة → بانتظار السعر → بانتظار التأكيد → مؤكد → مسنَد
   → في الطريق للاستلام → تم الاستلام → في الطريق للتسليم → تم التسليم
                                                    ↘ ملغي / متنازع عليه
```

| الحالة | مين يغيّرها | قاعدة |
|---|---|---|
| مسودة | العميل | مش ظاهر للسائقين |
| بانتظار السعر | النظام/الإدارة | للتسعير اليدوي بس |
| بانتظار التأكيد | الإدارة | العميل بيشوف السعر والشروط |
| مؤكد | **العميل** | 🔴 الإسناد **ما يبدأش** قبل تأكيد العميل |
| مسنَد | الإدارة/النظام | 🔴 دلوقتي بس بيظهر رقم السائق |
| تم الاستلام | السائق | صورة الإيصال إجبارية لو طلب شراء |
| تم التسليم | **رمز العميل** | 🔴 السائق **ما يقدرش** يقفل الطلب لوحده |
| ملغي / متنازع | الإدارة | سبب + سجل + مراجعة مالية إجبارية |

**رمز التسليم:** ٤ أرقام، يتولّد عند التأكيد، يظهر للعميل بس، السائق بيدخّله. الإدارة تقدر تتجاوزه — بس التجاوز **بيتسجل في `audit_logs` باسم الموظف**.

**كل انتقال حالة بيتسجل في `status_events`** بالوقت والشخص. ده سجلك في أي خلاف — مع عميل أو سائق أو محامي.

## ٥. الشاشات

### تطبيق العميل
| الشاشة | المحتوى | ملاحظة تنفيذ |
|---|---|---|
| التسجيل | تليفون + OTP + اختيار القرية | ❌ متطلبش بطاقة |
| الرئيسية | ٤ خدمات + آخر الطلبات + **ميعاد مشوار المحلة الجاي** | زر طلب كبير يشتغل بإيد واحدة |
| إنشاء الطلب | النوع + العناوين + التفاصيل + **صورة** + **صوت** | الصوت والصورة بارزين مش مخفيين |
| السعر والتأكيد | رسوم التوصيل + ثمن تقريبي + طريقة الدفع | 🔴 **افصل ثمن البضاعة عن أجرة التوصيل** |
| التتبع | الحالة + وقت تقريبي + السائق + زر اتصال | الرقم بعد الإسناد بس |
| التسليم | رمز ٤ أرقام + تقييم | |
| الدعم | اتصال / واتساب / شكوى | رقم الطلب ظاهر في كل محادثة |
| الحساب | العناوين + الطلبات + الخصوصية + **حذف الحساب** | حق الحذف مطلوب قانونًا |

### تطبيق السائق
| الشاشة | الوظيفة |
|---|---|
| التفعيل | المستندات + حالة المراجعة + تواريخ انتهاء الرخص |
| الرئيسية | متاح/غير متاح + الطلب الحالي + مستحقات اليوم |
| عرض الطلب | المنطقة + المسافة + **الأجرة** + نوع الغرض + مهلة ٦٠ ثانية |
| التنفيذ | وصلت للاستلام → استلمت → بدأت التوصيل → وصلت → رمز التسليم |
| الملاحة | فتح الاتجاهات برة + **نسخ العلامة المميزة** |
| النقدية | قيمة البضاعة + المطلوب تحصيله + العهدة + الفرق |
| المستحقات | طلبات اليوم + العمولة + الصافي + حالة التسوية |
| المساعدة | بلاغ حادث / مشكلة / العميل مش بيرد |

### لوحة الإدارة — دي الأهم فعليًا
> ⚠️ لو عندك وقت لحاجة واحدة بس، ابني اللوحة دي. تطبيق العميل ممكن يستنى — واتساب بيشتغل مكانه. اللوحة مالهاش بديل.

- لوحة لحظية: جديد · متأخر · جاري · مكتمل · ملغي
- **إنشاء طلب نيابة عن عميل** بيتصل أو بيبعت واتساب ← هتستخدمها أكتر من أي حاجة تانية في أول شهر
- تسعير يدوي أو سعر منطقة
- إسناد وتغيير السائق عند عدم الرد
- مراجعة مستندات السائقين + تعطيل + سقف قيمة
- إدارة المناطق والأسعار
- تسوية نقدية يومية
- **سجل كامل** لكل تغيير ومين عمله وإمتى
- شكاوى + استرداد جزئي + قائمة سوداء
- تقارير: الطلبات، الإيراد، وقت التوصيل، الإلغاء — حسب المنطقة والسائق والنوع

## ٦. قواعد عمل غير قابلة للتفاوض

هات الـAI يطبّق دي حرفيًا:

1. الإسناد ما يبدأش قبل تأكيد العميل للسعر.
2. رقم السائق ما يظهرش قبل الإسناد.
3. الطلب ما يتقفلش من غير رمز التسليم أو تجاوز إداري مسجَّل.
4. أي زيادة في ثمن المشتريات توقف الطلب لحد موافقة العميل.
5. السائق يشوف الطلب المسنَد له بس — على مستوى قاعدة البيانات.
6. ثمن البضاعة منفصل عن أجرة التوصيل في الشاشة والتقرير والتسوية.
7. مستندات السائقين في تخزين خاص، روابط مؤقتة، الموظف العادي ما يفتحهاش.
8. مفيش مفاتيح إنتاج في الكود ولا في تطبيق الهاتف.
9. السائق بيتعطّل **تلقائيًا** لما رخصته تنتهي.
10. كل فعل إداري حساس بيتسجل في `audit_logs`.
