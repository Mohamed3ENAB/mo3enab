# النسخة التجريبية

صفحة واحدة بتحاكي التطبيق عشان تجربه على الموبايل من غير نشر ولا قاعدة بيانات.

**مش التطبيق الحقيقي.** الفرق:

| | النسخة دي | التطبيق (`../`) |
|---|---|---|
| البيانات | مكتوبة جوه الصفحة، وهمية | PostgreSQL حقيقية |
| اللي بتغيّره | في متصفحك انت بس (localStorage) | بيتحفظ للكل |
| لوحة الإدارة | ❌ | ✅ |
| التسجيل الذاتي والموافقة | ❌ | ✅ |
| المحادثة | ❌ | ✅ |
| رفع الصور | ❌ | ✅ |
| زرار الاتصال | بيعرض الرقم عشان تنسخه | بيفتح الاتصال على طول |

سبب اختلاف زرار الاتصال: روابط `tel:` مش مضمونة جوه صفحة منشورة كده، فالأفضل تعرض
الرقم كنص يتنسخ بدل زرار ممكن ميعملش حاجة.

## تشغيلها محليًا

```bash
npx http-server delivery/web/demo -p 8080
```

ملف واحد مفيهوش أي اعتماديات غير خط Google Fonts.
