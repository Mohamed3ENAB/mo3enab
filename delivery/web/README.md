# في السكة — التطبيق

دليل السواقين والتوك توك المتاحين في القيصرية والمناطق المجاورة.
تطبيق ويب تقدمي (PWA) عربي، بيشتغل من لينك واحد على أي موبايل.

> الفكرة والقرارات في `../README.md` · المواصفة في `../01-spec.md`

---

## شغّله على جهازك

محتاج **Node 20+** و**PostgreSQL 14+** (أو حساب Supabase مجاني).

```bash
cp .env.example .env     # وظبط القيم جواه
npm install
npm run db:setup         # بيعمل الجداول ويحط القرى والأسعار
npm run db:seed-demo     # بيانات تجريبية + لينكات سواقين للاختبار
npm run dev
```

افتح http://localhost:3000

| الصفحة | اللينك |
|---|---|
| دليل السواقين | `/` |
| دليل المحلات والمطاعم | `/places` |
| لوحة الطلبات | `/requests` |
| الأسعار | `/prices` |
| اشتغل معانا | `/join` |
| سجّل نفسك (سائق أو محل) | `/join/apply` |
| صفحة محل + آراء | `/m/<id>` |
| محادثة صاحب الطلب | `/t/<token>` |
| محادثة السائق | `/t/p/<driver-token>/<request-id>` |
| صفحة سائق | `/p/<id>` |
| **لينك السائق الخاص** | `/d/<token>` — من لوحة الإدارة أو `db:seed-demo` |
| لوحة الإدارة | `/admin` |

## متغيرات البيئة

| المتغير | إيه ده |
|---|---|
| `DATABASE_URL` | رابط PostgreSQL. من Supabase: Settings → Database → Connection string |
| `ADMIN_PASSWORD` | كلمة سر لوحة الإدارة. 🔴 غيّرها |
| `SESSION_SECRET` | سر توقيع كوكي الدخول. ولّده بـ `openssl rand -hex 32` |
| `NEXT_PUBLIC_SUPPORT_PHONE` | رقم الدعم اللي يظهر في التذييل |

🔴 **`.env` مش بيترفع على Git** (موجود في `.gitignore`). على Vercel حطهم في Settings → Environment Variables.

## التصميم

شكل تطبيقات التوصيل المعروفة: هيدر بتدرج أخضر، كارت بحث عايم فوقه، أيقونات خدمات ملوّنة،
كروت بظل وأفاتار وشارة توثيق، شريط تنقل سفلي، وورقة سفلية (bottom sheet) للتفاصيل.

- **الألوان** في `src/app/globals.css` تحت `:root` — غيّر `--brand-600` وهيتغير التطبيق كله.
- **الأيقونات** مرسومة SVG بالإيد في `src/components/icons.tsx` — من غير مكتبة خارجية.
  التوك توك مش موجود في أي مكتبة أيقونات، فاترسم مخصوص.
- **الحركة**: دخول متتابع للكروت، نبضة على علامة «متاح»، انزلاق للورقة السفلية،
  وضغطة بتصغّر الزرار. كلها بتتوقف مع `prefers-reduced-motion`.
- **وضع ليلي** كامل عبر `prefers-color-scheme`.

## قرارات مهمة في الكود

**المتصفح مبيكلمش قاعدة البيانات.** كل قراءة وكتابة بتعدي من السيرفر (`lib/db.ts` و`app/actions.ts`). التحكم في الصلاحيات هناك، مش في الواجهة. عشان كده `db/rls-supabase.sql` اختياري.

**مفيش تسجيل للعملاء.** أي حد يفتح اللينك ويشوف ويتصل. ده بيشيل تكلفة رسايل الـSMS وأكبر حتة معقدة في البناء.

**لينك السائق بدل كلمة السر.** التوكن في جدول منفصل (`provider_tokens`) عشان ما يتقراش مع البيانات العامة، والتبديل بيحصل بدالة `toggle_availability` في قاعدة البيانات.

**التوفر بينتهي بعد ٤ ساعات.** في `is_live()` في قاعدة البيانات، مش في الواجهة — عشان ما ينفعش يتلف حواليه.

**`services::text[]`** في كل استعلام: مكتبة `pg` مبتعرفش تفك مصفوفة enum مخصصة وبترجعها نص. التحويل ده مطلوب.

**الصور متخزنة في قاعدة البيانات.** الصورة بتتصغّر لـ 256×256 webp قبل التخزين
(صورة موبايل 4 ميجا بتبقى ~15 كيلو)، وبتتقدّم من `/img/<id>` بكاش دائم. مفيش خدمة
تخزين زيادة تظبطها وتدفع فيها، والعدد هنا مش هيوصل لحد يستدعي غير كده.

**التسجيل الذاتي بموافقة.** أي حد يقدر يسجّل نفسه من `/join/apply`، بس الطلب بيقعد
في `applications` لحد ما الإدارة تقبله. مفيش حاجة بتظهر في الدليل لوحدها — ده اللي
بيحافظ على معنى «موثّق».

**المحادثة من غير حسابات.** كل طلب على اللوحة بياخد خيط تلقائي (تريجر في قاعدة
البيانات). صاحب الطلب بياخد لينك سري، والسائق بيرد من لينكه السري اللي عنده أصلاً —
نفس فكرة زرار التوفر.

**دليلين مربوطين ببعض.** دليل السواقين ودليل المحلات. كارت المحل فيه زرار
«اطلب من هنا» بيفتح ورقة بخطوتين: كلّم المحل، وبعدين كلّم سائق متاح يستلم منه —
ورسالة الواتساب للسائق بتتكتب لوحدها باسم المحل ومكانه. ده اللي بيخلي الدليلين
منتج واحد مش قايمتين منفصلتين.

**سعر بداية لكل مركبة** في `vehicle_rates`. العجلة أرخص حاجة (٥ ج) عن قصد: الطلب
القريب مش محتاج موتوسيكل، وده بيخلي أي حد عنده عجلة يقدر يبدأ.

**رقم صاحب الطلب مخفي افتراضيًا.** دليل السواقين والمحلات بيعرض الأرقام عن قصد — دي
الخدمة. إنما صاحب الطلب على اللوحة مواطن عادي، فرقمه مخفي افتراضيًا وبيظهر ناقص
(`0101••••78`)، و**الرقم الحقيقي مبيخرجش من الاستعلام أصلًا** (`case when hide_phone
then null`) فمش موجود في HTML الصفحة. التواصل بيبقى من المحادثة.

**غلاف أصلي بـ Capacitor** في `android/` و `ios/`. التطبيق بيفتح الموقع المنشور
(`server.url`) لأن صفحاته بتتبني على السيرفر، يعني أي تعديل في الواجهة بيوصل
للتطبيقين من غير رفع نسخة جديدة للمتجر.

**الفلترة والبحث في المتصفح.** الدليل بيتحمّل مرة واحدة والفلاتر شغالة على الجهاز — من غير
طلب سيرفر لكل ضغطة. مناسب لحجم بلد (عشرات السواقين مش آلاف).

## الاختبارات

```bash
npm run typecheck
npm run build

# اختبار الرحلات على متصفح حقيقي
npx playwright install chromium      # أول مرة بس
npm start &
npm run test:e2e -- http://127.0.0.1:3000 <DRIVER_TOKEN>
```

`tests/e2e.mjs` بيختبر ٤٣ حاجة: دليل السواقين بدون تسجيل، زر الاتصال، السائق يفتح ويقفل توفره والدليل يتحدث، فلتر الخدمة، البحث بالاسم، اللينك الغلط، نشر طلب، رفض الرقم الغلط، دليل المحلات بدون تسجيل، فلتر التصنيف، ورقة الطلب بخطوتين وسواقينها ورسالة الاستلام الجاهزة، سعر بداية العجلة في صفحتين، حماية `/admin`، رفض كلمة السر الغلط، الدخول، الإيقاف بيخفي السائق فورًا، إخفاء محل بيشيله فورًا، ولينكات السواقين مش ظاهرة للزائر · التسجيل الذاتي برفع صورة · الطلب مايظهرش قبل الموافقة · رفض الطلب المكرر · موافقة الإدارة بتفعّل الحساب · الصورة بتتصغّر وبتتكاش · الريفيو بيظهر بالاسم · المحادثة بين صاحب الطلب والسائق.

> ⚠️ شغّل الاختبارات على نسخة الإنتاج (`npm run build && npm start`) مش على `npm run dev`.
