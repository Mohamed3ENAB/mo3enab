# النشر والتطبيقات — iPhone و Android

> اقرا القسم الأول الأول. فيه حاجة تقدر تجربها على الأيفون **النهاردة** من غير ماك ومن غير حساب مطوّر ومن غير مليم.

---

## 🔴 أول حاجة لازم تعرفها

**أنا معملتش الحاجات دي وماقدرش أعملها:**

| الحاجة | ليه لأ |
|---|---|
| رفع التطبيق على App Store أو Google Play | محتاج حسابك ومفاتيحك. ماينفعش ولا المفروض حد تاني يعملها بدالك |
| بناء ملف iOS (`.ipa`) | محتاج جهاز **ماك** وعليه Xcode. البيئة اللي شغال فيها لينكس |
| بناء ملف Android (`.apk`) | جربت فعليًا وفشل: `dl.google.com` محجوب في البيئة دي، ومنها بتتحمّل أدوات أندرويد |
| إنشاء حسابات المطوّرين | بياناتك الشخصية وبطاقتك |

**اللي عملته:** مشروعين أصليين جاهزين (`android/` و `ios/`) بالأيقونات وشاشات البداية والاسم العربي، تفتحهم على جهازك وتبني منهم بأمر واحد.

## ١. جرّب على الأيفون النهاردة (٥ دقايق)

التطبيق **PWA** — يعني بيتثبّت على شاشة الموبايل من المتصفح على طول، من غير متجر.

**بس محتاج ينشر على لينك عام الأول** (القسم ٢ تحت، ١٥ دقيقة). وبعدها:

**على الأيفون:**
1. افتح اللينك في **سفاري** (مش كروم — التثبيت في iOS بيشتغل من سفاري بس)
2. اضغط زرار المشاركة (المربع اللي عليه سهم لفوق)
3. انزل تحت واختار **«إضافة إلى الشاشة الرئيسية»**
4. هتلاقي الأيقونة على شاشتك — تفتح على طول من غير شريط المتصفح

**على الأندرويد:** كروم هيعرض «تثبيت التطبيق» لوحده، أو من القائمة ← «تثبيت التطبيق».

> 💡 دي مش نسخة ناقصة — دي التطبيق كامل. الفرق الوحيد عن نسخة المتجر إن التحديث بيوصل على طول من غير مراجعة.

## ٢. انشر التطبيق (١٥ دقيقة) — لازم قبل أي حاجة تانية

### قاعدة البيانات
1. اعمل حساب مجاني على [supabase.com](https://supabase.com) ← مشروع جديد
2. Settings ← Database ← انسخ **Connection string**
3. على جهازك:
   ```bash
   cd delivery/web
   cp .env.example .env     # وحط الرابط في DATABASE_URL
   npm install
   npm run db:setup
   ```

### الموقع
1. ارفع الريبو على GitHub (اتعمل خلاص)
2. [vercel.com](https://vercel.com) ← New Project ← اختار الريبو
3. 🔴 **Root Directory: `delivery/web`**
4. Environment Variables — حط الأربعة:
   - `DATABASE_URL` — من Supabase
   - `ADMIN_PASSWORD` — كلمة سر قوية
   - `SESSION_SECRET` — ولّدها بـ `openssl rand -hex 32`
   - `NEXT_PUBLIC_SUPPORT_PHONE` — رقمك
5. Deploy

هتطلع بلينك زي `https://fi-el-sekka.vercel.app`. **ده اللينك اللي هتوزّعه على الناس.**

## ٣. تطبيق أندرويد (.apk)

**محتاج:** [Android Studio](https://developer.android.com/studio) على جهازك · مجانًا.

```bash
cd delivery/web
npm install
SEKKA_APP_URL=https://your-app.vercel.app npx cap sync android
cd android
./gradlew assembleDebug
```

الملف هيطلع في:
`android/app/build/outputs/apk/debug/app-debug.apk`

ابعته لنفسك على واتساب وثبّته (هيطلب «السماح بتثبيت من مصادر غير معروفة»). ده كافي للتجربة وللتوزيع على ناس تعرفها.

**لنسخة المتجر** محتاج توقيع:
```bash
keytool -genkey -v -keystore sekka.keystore -alias sekka \
        -keyalg RSA -keysize 2048 -validity 10000
./gradlew bundleRelease      # بيطلع .aab وده اللي Google Play بياخده
```
🔴 **احتفظ بملف `sekka.keystore` وكلمة سره في مكان آمن.** لو ضاع، مش هتقدر تحدّث التطبيق على المتجر تاني أبدًا — هتضطر تنشره باسم جديد وتخسر كل اللي نزّلوه.

## ٤. تطبيق iOS (.ipa)

**محتاج:** جهاز **ماك** + Xcode. مفيش طريقة تانية — أبل ما بتسمحش ببناء iOS على ويندوز أو لينكس.

```bash
cd delivery/web
SEKKA_APP_URL=https://your-app.vercel.app npx cap sync ios
npx cap open ios
```

في Xcode: Signing & Capabilities ← اختار حسابك ← وصّل الأيفون ← ▶️

> **على أيفونك الشخصي** تقدر تشغّله بحساب Apple ID عادي مجاني، بس بينتهي بعد **٧ أيام** ولازم تعيد التثبيت. للتوزيع الدائم محتاج حساب المطوّر المدفوع.

## ٥. المتاجر — التكلفة والوقت والمخاطرة

| | Google Play | App Store |
|---|---|---|
| الحساب | ٢٥ دولار مرة واحدة | ٩٩ دولار **في السنة** |
| مدة المراجعة | ساعات لأيام | يوم لأسبوع |
| المطلوب | حساب Google | Apple ID + جهاز ماك |

**محتاج تجهّز:** أيقونة (موجودة) · صور من التطبيق · وصف عربي · **سياسة خصوصية على لينك عام** (إجباري في الاتنين — عندك المحتوى في `../05-legal.md`) · تصنيف عمري · بيانات جهة الاتصال.

### ⚠️ مخاطرة حقيقية لازم تعرفها

أبل عندها قاعدة اسمها **Guideline 4.2 — Minimum Functionality**، وبترفض بيها التطبيقات اللي مجرد «موقع متغلّف». وتطبيقك دلوقتي **بالظبط كده**: غلاف حوالين موقع.

يعني احتمال الرفض من أبل **عالي**. اللي بيقلله إنك تضيف حاجات أصلية حقيقية: **إشعارات** لما ييجي طلب جديد، فتح جهات الاتصال، مشاركة أصلية. أقلهم فايدة وأهمهم: **الإشعارات**.

جوجل بلاي أسهل بكتير في النقطة دي.

### 🤔 وصراحة: هل انت محتاج المتاجر أصلاً؟

خد بالك من ده قبل ما تدفع:

| PWA (اللينك) | المتجر |
|---|---|
| ✅ ببلاش | ٢٥ + ٩٩ دولار سنويًا |
| ✅ لينك واحد يشتغل على الاتنين | نسختين منفصلتين |
| ✅ التحديث يوصل في ثانية | مراجعة كل تحديث |
| ✅ محدش بيرفضك | ممكن أبل ترفض |
| ✅ الناس بتفتحه من واتساب على طول | لازم يدوّروا ويحمّلوا |
| ❌ مش في نتايج بحث المتجر | ✅ ظهور في المتجر |
| ❌ إشعارات iOS محدودة | ✅ إشعارات كاملة |

لخدمة مجتمعية في قرية، **رسالة واتساب فيها اللينك بتوصل لناس أكتر من المتجر بكتير** — ومحدش هيحمّل تطبيق عشان يشوف مين سائق فاضي.

**اقتراحي:** ابدأ بالـPWA وشوف هل الناس بتستخدمه. لو نجح ولقيت إن الناس بتطلب نسخة من المتجر، ساعتها ادفع — والمشاريع جاهزة عندك في `android/` و `ios/` مستنية.

## ٦. بعد أي تعديل في الكود

```bash
git push                                              # Vercel بيحدّث لوحده
SEKKA_APP_URL=https://your-app.vercel.app npx cap sync # للتطبيقات الأصلية
```

الغلاف بيفتح الموقع المنشور، يعني **أي تعديل في الواجهة بيوصل للتطبيقات من غير ما ترفع نسخة جديدة للمتجر**. المتجر بس لما تغيّر حاجة في الغلاف نفسه (الأيقونة، الاسم، الصلاحيات).
