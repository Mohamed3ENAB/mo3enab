## اللي خلص ✅

| الحاجة | فين |
|---|---|
| صفحة الدليل — المتاح فوق و«حدّث من X دقيقة» | `web/src/app/page.tsx` |
| فلتر القرية ونوع الخدمة | نفس الصفحة |
| أزرار اتصال وواتساب مباشرة | `web/src/components/ProviderRow.tsx` |
| لينك السائق الخاص — زرار واحد للتوفر | `web/src/app/d/[token]/` |
| التوفر بينتهي تلقائيًا بعد ٤ ساعات | `is_live()` في `db/schema.sql` |
| لوحة الطلبات المفتوحة (بتنتهي بعد ٦ ساعات) | `web/src/app/requests/` |
| تقييم وبلاغ | `web/src/app/p/[id]/` |
| الأسعار الاسترشادية | `web/src/app/prices/` |
| لوحة الإدارة: إضافة · توثيق · إيقاف · لينكات · بلاغات · إخفاء طلب | `web/src/app/admin/` |
| إخلاء المسؤولية في كل صفحة | `web/src/components/Foot.tsx` |
| وضع ليلي · RTL · خط واحد · من غير خرايط | `web/src/app/globals.css` |
| PWA — يتثبّت على شاشة الموبايل | `web/src/app/manifest.ts` |

## اللي اتأكد منه ✅

**١٣ اختبار على متصفح حقيقي** (`web/tests/e2e.mjs`) — كلها عدّت:

الزائر يشوف الدليل من غير تسجيل · زر الاتصال بيفتح الاتصال فعلاً · السائق يقفل توفره فيختفي من المتاحين فورًا · يفتحه فيرجع يظهر · اللينك الغلط بيرجع ٤٠٤ · نشر طلب في اللوحة · رقم الموبايل الغلط بيترفض برسالة واضحة · `/admin` بترمي على الدخول · كلمة السر الغلط بترفض · الدخول بيشتغل · الإيقاف بيخفي السائق فورًا · **لينكات السواقين مش ظاهرة للزائر في أي صفحة**.

كمان: `npm run typecheck` و`npm run build` بيعدوا، و`npm audit` صفر ثغرات.

## مؤجل — ومتى تفكر فيه

| الميزة | الشرط |
|---|---|
| إشعار للسواقين بالطلبات الجديدة | لوحة الطلبات بتتستخدم فعلاً كل يوم |
| مشوار المحلة المشترك في التطبيق | جرّبه في جروب واتساب الأول (`02-prices.md`) |
| صور السواقين | السواقين نفسهم طلبوها |
| توسيع لقرى تانية | الخمسة الحاليين شغالين كويس |
| تطبيق أصلي (Flutter) | الـPWA وقف في وشك فعلاً — مش قبل كده |
| صلاحيات على مستوى الصفوف في المتصفح | لو خليت المتصفح يكلم Supabase مباشرة (`db/rls-supabase.sql` جاهز) |
| أي حاجة فيها فلوس | قرار مختلف تمامًا — اقرا `05-legal.md` الأول |
