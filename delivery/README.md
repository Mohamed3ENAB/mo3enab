# في السكة — خدمة مجتمعية لأهل القيصرية والمناطق المجاورة

> **الهدف:** تسهّل على الناس. مش مشروع ربحي — على الأقل مش دلوقتي.
> **المشكلة اللي بنحلها:** مش "مفيش سواقين"، المشكلة **"مين متاح دلوقتي؟"**
> **النطاق:** القيصرية · بطينة · محلة أبو علي · محلة زياد · المحلة الكبرى.

---

## الفكرة في سطرين

مش تطبيق توصيل بعمولة. ده **دليل حي** للسواقين والتوك توك في البلد: تفتح اللينك، تشوف **مين متاح دلوقتي**، تضغط اتصال، تتفق معاه أنت. خلاص.

**ومش مشكلة خالص إن العميل ياخد رقم السائق بعد كده** — ده مش تسريب، ده الهدف. القيمة مش في إننا وسيط، القيمة في إنك لما السائق بتاعك مش متاح، تلاقي **حد تاني متاح** بدل ما تفضل تكلم أربعة وخمسة وهما مقفلين.

---

## اللي اتغير عن النسخة اللي قبل كده

النسخة الأولى من الملفات دي كانت متبنية على إنه مشروع بعمولة. ده كان غلط في فهم هدفك، وبيتصحح هنا:

| الحاجة | النسخة القديمة (بعمولة) | **النسخة الصح (خدمة مجتمعية)** |
|---|---|---|
| أرقام السواقين | تتخفي لحد الإسناد | ✅ **ظاهرة من الأول** — دي الخدمة نفسها |
| الالتفاف حوالين التطبيق | أخطر مخاطرة | ❌ **مش مخاطرة خالص** — ده المطلوب |
| الإسناد | المنصة بتسنِد | ❌ اتشال. الناس بتتفق مع بعضها |
| الفلوس والعهدة والتسويات | نظام كامل | ❌ **اتشال كله.** إحنا مش بنمسك فلوس |
| تسجيل العميل | تليفون + OTP | ❌ **مفيش تسجيل خالص.** افتح اللينك وشوف |
| حالات الطلب (١١ حالة) | دورة كاملة | ❌ اتشالت |
| التوك توك | مؤجل | ✅ **من اليوم الأول** — اقرا القسم القانوني |
| حجم قاعدة البيانات | ٢٢ جدول | ✅ **٩ جداول** |
| وقت البناء | ٤ أسابيع | ✅ **٢–٣ أيام** |

**المكسب:** المشروع بقى حاجة تقدر تطلّعها الأسبوع ده فعلاً، مش بعد شهر.

## التوك توك — دلوقتي، مش مؤجل

كنت قلتلك أجّله. ده كان صح **لو** كنت هتشغّل شركة نقل ركاب — تسنِد رحلات، تحدد أسعار، وتاخد نسبة. ساعتها قانون ٨٧ لسنة ٢٠١٨ بينطبق وبيحتاج ترخيص.

**إنما اللي بتعمله ده حاجة تانية:** صفحة فيها أرقام ناس بتشتغل في البلد أصلاً، والناس بتكلمهم وبتتفق معاهم زي ما بتعمل كل يوم. ده **دليل**، مش شركة نقل. المسؤولية أقل بكتير.

اللي يخليك في المنطقة الآمنة — ٤ شروط، التزم بيهم:

1. ❌ **متاخدش فلوس** من سائق ولا راكب على الخدمة.
2. ❌ **متحددش سعر ملزم.** الأسعار اللي في `02-prices.md` **استرشادية** ومكتوب عليها كده بوضوح.
3. ❌ **متسنِدش رحلات.** الناس بتتصل بنفسها.
4. ✅ **اكتب إخلاء مسؤولية واضح** في الصفحة: إحنا بنعرض بيانات، والاتفاق والمسؤولية بين الطرفين.

⚠️ برضه: راجع محامي قبل ما تكبر. ودي مش نصيحة قانونية — بس الفرق بين "دليل" و"شركة نقل" فرق حقيقي ومهم.

## أهم قرار تقني: مفيش حسابات

**العميل:** مفيش تسجيل ولا OTP ولا كلمة سر. يفتح اللينك ويشوف. ده بيوفر تكلفة الرسائل (أكبر تكلفة شهرية) وبيشيل أكبر حاجة معقدة في البناء، وبيخلي أي حد في البلد يقدر يستخدمه من أول ثانية.

**السائق:** برضه مفيش كلمة سر. كل سائق بياخد **لينك خاص بيه** يفتحه ويضغط زرار واحد: «أنا متاح» / «مش متاح». بس.

**أنت (الإدارة):** لوحة بسيطة بكلمة سر — تضيف سائق، توثّقه، توقفه.

> 💡 **ليه التوفر بيقع في تطبيقات زي دي؟** السائق بينسى يقفل الزرار وهو مشغول، فالقايمة بتقول "متاح" وهو مش متاح — وساعتها الناس بتفقد الثقة وتسيب التطبيق. الحل: **التوفر بينتهي تلقائيًا بعد ٤ ساعات**، والصفحة بتقول «متاح — حدّث من ٢٠ دقيقة» بدل «متاح» المجردة. الصدق أهم من إن القايمة تبان مليانة.

## ملاحظة على الاستمرارية (مش ربح)

الخدمة المجتمعية اللي بتقفل بعد ٣ شهور مبتفدش حد. خلي التكاليف قريبة من الصفر عشان تعيش:

- الاستضافة وقاعدة البيانات: ابدأ بالحدود المجانية (Supabase / Vercel) — كفاية أضعاف حجمك.
- **مفيش رسائل SMS** — ده أكبر بند كان هيكلفك، وشيلناه بإلغاء التسجيل.
- الخرائط: **متستخدمهاش**. العلامة المميزة والتليفون بيكفوا في البلد.
- لو كبرت واحتجت مصاريف، الحل مش عمولة — ممكن محل أو اتنين يرعوا الخدمة، أو مساهمة رمزية من السواقين. قرار بعدين.

## ابدأ إزاي

**التطبيق اتبنى خلاص.** اللي ناقص مش كود — ناس.

1. **النهاردة:** اجمع ١٠ سواقين، شوف بطاقاتهم، وخد موافقة مكتوبة على نشر أرقامهم (`03-operations.md`).
2. **بعدها:** انشر التطبيق على Vercel + Supabase (`web/README.md` فيه الخطوات).
3. **وانت بتجمع:** شغّل جروب واتساب بالقائمة مكتوبة — كده الخدمة تبدأ قبل ما حد يفتح لينك.

```bash
cd web
cp .env.example .env
npm install && npm run db:setup && npm run dev
```

## حالة التحقق

ملفات قاعدة البيانات **اتنفّذت فعليًا** على PostgreSQL 16، مش مكتوبة ومتسابة:

| الاختبار | النتيجة |
|---|---|
| `schema.sql` + `seed.sql` | ✅ بيتنفّذوا نضيف |
| الزائر يقرا الدليل من غير تسجيل | ✅ شغال |
| 🔴 الزائر يقرا لينكات السواقين | ✅ **مرفوض** (permission denied) |
| 🔴 الزائر يقرا البلاغات | ✅ **مرفوض** |
| 🔴 الزائر يعدّل بيانات سائق | ✅ **مرفوض** |
| 🔴 الزائر يمسح طلب من اللوحة | ✅ **مرفوض** |
| اللينك الخاص بيغيّر التوفر | ✅ شغال |
| لينك غلط | ✅ مرفوض |
| التوفر بينتهي بعد ٤ ساعات | ✅ شغال |
| السائق الموقوف بيختفي | ✅ فورًا |
| أي حد يكتب في لوحة الطلبات | ✅ شغال |

**اللي لسه متأكدش عليه** (محتاج الكود نفسه): الواجهات، وتكامل Supabase الحقيقي، والشكل على موبايل فعلي.

**والباقي تقديرات:** الأسعار في `02-prices.md` **لازم تتأكد منها بالسؤال** قبل ما تنشرها، والقانوني قائمة أسئلة لمحامي مش رأي قانوني.
