# في السكة — بنية المشروع

تطبيق ويب مجتمعي لقرية القيصرية والقرى المجاورة: دليل سواقين ومحلات،
لوحة طلبات، محادثة داخلية، وحسابات بأربع أدوار لكل واحد داش بورد خاصة بيه.

للتنصيب على استضافة: **[اقرأني-التنصيب.md](اقرأني-التنصيب.md)**.

---

## الأدوار والداش بوردات

| الدور | بيعمل إيه | المسار |
|---|---|---|
| `admin` | يوافق على الطلبات، يدير السواقين والمحلات والحسابات والبلاغات والأسعار | `/admin` |
| `customer` | ينشر طلبات، يتابعها، مفضلة، تقييمات | `/dashboard/customer` |
| `driver` | يفتح ويقفل التوفر، يستلم الطلبات، يعدّل ملفه ومستنداته | `/dashboard/driver` |
| `merchant` | يفتح ويقفل المحل، يعدّل بياناته، يشوف تقييماته | `/dashboard/merchant` |

السائق والمحل بيتسجّلوا بأنفسهم بحالة `pending`، وبيفضلوا على `/dashboard/pending`
لحد ما الإدارة توافق. العميل بيشتغل على طول.

## قرارات هندسية

| القرار | السبب |
|---|---|
| **PHP مش Node.js** | الاستضافة المشتركة على هوستنجر مفيهاش Node |
| **الصور في قاعدة البيانات كـ BLOB** | مفيش صلاحيات مجلدات تتظبط، والباك أب بياخد الصور معاه. صورة الحساب بتتحفظ 512×512 والمستندات أكبر ضلع 1400 |
| **جلسات PHP مش كوكي موقّع** | الأدوار محتاجة حالة في السيرفر، والجلسة بتتجدّد كل ساعة |
| **الأيقونة بترسم في `icon.php`** | أي مقاس بيتولد لوحده، ومفيش ملفات PNG تتنسى تتحدّث |
| **الأصوات متولّدة بـ WebAudio** | مفيش ملفات صوت تتحمّل، والصوت مقفول افتراضيًا |
| **الرقم المخفي مبيخرجش من قاعدة البيانات** | `CASE WHEN hide_phone THEN NULL` — القناع بيتعمل في SQL، فالرقم الحقيقي مش في الـ HTML خالص |
| **كل POST بيعدي على `guard_post()`** | فحص CSRF مرة واحدة في الراوتر بدل ما كل صفحة تفتكر تعمله |
| **`ALTER TABLE` في install.php** | التنصيب بيشتغل على قاعدة فاضية وعلى قاعدة قديمة فيها بيانات |

## حاجات لازم تفضل زي ما هي

### 🔴 `[hidden]` في أول `assets/app.css`

```css
[hidden] { display: none !important; }
```

قاعدة `[hidden]` بتاعة المتصفح ضعيفة، وأي `display` في كلاس بيغلبها.
من غير السطر ده، الصفوف المفلترة بتفضل ظاهرة. **لو اتشال، الموقع هيتكسر بصريًا.**

### 🔴 مفيش `required` على `input[type=file]` مخفي

حقول الصور مخفية جوه `label` عشان الشكل. لو حطيت `required` عليها،
كروم بيوقف الإرسال بصمت برسالة `not focusable` في الكونسول والمستخدم
مش بيفهم إيه اللي حصل. الفحص بيتعمل في `app.js` (رسالة عربي واضحة)
وفي السيرفر (`read_signup_files`) — والسيرفر هو الفحص الحقيقي.

### 🔴 صور المستندات `is_private = 1`

البطاقة والرخصة بتتخزن بالعَلم ده، و`img.php` مش بيقدّمها غير للإدارة
أو لصاحبها، وبكاش `no-store`. و`sw.js` مش بيخزّن `img.php` خالص.

## الأمان

- كل الاستعلامات PDO ببارامترات مربوطة — مفيش دمج نصوص في SQL.
- كلمات السر `password_hash` + `password_verify`، وبتتجدّد الخوارزمية لوحدها.
- ٦ محاولات دخول غلط = قفل ١٥ دقيقة.
- كل POST فيه توكن CSRF بيتفحص في الراوتر.
- الجلسة بتتجدّد كل ساعة، وكوكي `HttpOnly` + `SameSite=Lax` + `Secure` على HTTPS.
- رفع الصور بيتفحص من **بايتات الصورة نفسها** (`getimagesizefromstring`)،
  مش من الامتداد ولا الـ MIME اللي المتصفح بعته — الاتنين ممكن يتزوّروا.
  PDF وأي ملف مش صورة بيترفض.
