# في السكة — نسخة PHP

نفس التطبيق، مكتوب PHP + MySQL عشان يشتغل على أي استضافة مشتركة (هوستنجر وغيرها).

**للتنصيب اقرا [`اقرأني-التنصيب.md`](./اقرأني-التنصيب.md).**

## ليه PHP مش Next.js

الاستضافة المشتركة مفيهاش Node.js. نسخة `../web` (Next.js) محتاجة سيرفر Node،
وده موجود في VPS أو Vercel بس. النسخة دي بتشتغل على أي استضافة فيها PHP و MySQL.

الاتنين بيعملوا نفس الحاجة وبنفس الشكل بالظبط — نفس ملف التصميم ونفس الأيقونات.

## البنية

```
index.php            الراوتر
img.php              تقديم الصور من قاعدة البيانات
install.php          🔴 امسحه بعد التنصيب
config.example.php   انسخه لـ config.php
.htaccess            اللينكات النضيفة + الحماية
manifest.webmanifest إعدادات تثبيت التطبيق
sw.js                service worker
offline.html         صفحة «مفيش نت»
lib/                 db · helpers · auth · images · queries · ui · icons
views/               الصفحات
assets/              app.css · app.js · الأيقونات
sql/schema.sql       جداول قاعدة البيانات
tests-e2e.mjs        ٢٨ اختبار على متصفح حقيقي
```

## التشغيل محليًا

```bash
cp config.example.php config.php   # وظبط بيانات MySQL
php -S 127.0.0.1:8090 router.php
# افتح http://127.0.0.1:8090/install.php
```

## قرارات في الكود

**الصور في قاعدة البيانات مش في مجلد.** بتتصغّر لـ 256×256 webp بـGD قبل التخزين
(صورة 4 ميجا بتبقى ~15 كيلو). كده مفيش صلاحيات مجلدات، والباك أب بياخد الصور معاه.

**الرقم المخفي مبيخرجش من قاعدة البيانات.** `CASE WHEN hide_phone THEN NULL` —
القناع بيتعمل في SQL، فالرقم الحقيقي مش موجود في HTML خالص.

**كل الاستعلامات بـPDO بارامترات مربوطة.** مفيش دمج نصوص في SQL في أي مكان.

**نماذج الإدارة كلها فيها CSRF token.**

**🔴 `[hidden] { display: none !important }` في أول الـCSS.** قاعدة المتصفح ضعيفة
وأي `display` في كلاس بيغلبها — من غير السطر ده الأوراق المقفولة بتغطي الصفحة
والصفوف المفلترة بتفضل ظاهرة. اتصلحت بعد ما الاختبارات كشفتها.
