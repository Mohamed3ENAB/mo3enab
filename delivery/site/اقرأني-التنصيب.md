# تنصيب «في السكة» على هوستنجر — خطوة بخطوة

الكلام ده لأي حد، مش لازم تكون مبرمج. ١٥ دقيقة وتخلص.

---

## ١. اعمل قاعدة بيانات

1. ادخل على **hPanel** بتاع هوستنجر.
2. **Databases → MySQL Databases**.
3. اعمل قاعدة جديدة، واكتب:
   - اسم القاعدة (مثلًا `sekka`)
   - اسم المستخدم
   - كلمة سر قوية
4. اضغط **Create** واحتفظ بالتلات حاجات دول في ورقة — هتحتاجهم في الخطوة الجاية.

> هوستنجر بيحط بادئة قدام الأسماء (زي `u123456789_sekka`). استخدم الاسم الكامل زي ما هو ظاهر عندك.

---

## ٢. ارفع الملفات

1. **Files → File Manager**.
2. ادخل على مجلد `public_html`.
3. ارفع ملف `سكة.zip` جواه.
4. اضغط عليه يمين → **Extract** → استخرج في نفس المكان.
5. اتأكد إن `index.php` بقى جوه `public_html` مباشرة، مش جوه مجلد تاني.

> لو عايز التطبيق يبقى على `mysite.com/sekka` بدل الصفحة الرئيسية، اعمل مجلد `sekka` جوه `public_html` وحط الملفات فيه.

---

## ٣. ظبّط `config.php`

1. في File Manager، لاقي ملف `config.example.php`.
2. اعمله **Copy** وسمّي النسخة `config.php`.
3. افتح `config.php` (كليك يمين → Edit) وحط بيانات القاعدة:

```php
'db_host' => 'localhost',
'db_name' => 'u123456789_sekka',     // اسم القاعدة كامل
'db_user' => 'u123456789_admin',     // اسم المستخدم كامل
'db_pass' => 'كلمة السر بتاعتك',
'support_phone' => '01xxxxxxxxx',    // رقمك للشكاوى (اختياري)
```

4. احفظ.

> ⚠️ `config.php` فيه كلمة سر قاعدة البيانات. متبعتهوش لحد ومترفعهوش على جيت هاب.

---

## ٤. افتح صفحة التنصيب

1. افتح المتصفح على: `https://دومينك/install.php`
2. الصفحة هتقولك السيرفر فيه إيه وناقصه إيه.
3. اكتب **اسمك ورقم موبايلك وكلمة سر** — دا حساب الإدارة بتاعك.
4. اضغط **جهّز التطبيق**.

الصفحة هتعمل كل الجداول لوحدها، وتحط المناطق الخمسة والأسعار المبدئية.

---

## ٥. 🔴 امسح `install.php`

**دي أهم خطوة.** ارجع لـ File Manager وامسح ملف `install.php` خالص.

سيبانه معناه إن أي حد يفتح اللينك ده يقدر يعبث بالتطبيق.

---

## ٦. جرّب

| افتح | المفروض تشوف |
|---|---|
| `https://دومينك/` | الصفحة الرئيسية والدليل |
| `https://دومينك/login` | تسجيل الدخول — ادخل بحساب الإدارة |
| `https://دومينك/admin` | لوحة الإدارة |
| `https://دومينك/register` | اختيار نوع الحساب |

جرّب كمان من الموبايل، ودوس «إضافة إلى الشاشة الرئيسية» عشان يشتغل زي تطبيق.

---

## بعد ما تخلص

### تسجيل السواقين والمحلات
سيبهم يسجّلوا بنفسهم من `/register`. هيرفعوا صورهم وبطاقتهم ورخصتهم،
وإنت بتراجع من **لوحة الإدارة → طلبات الانضمام** وتوافق أو ترفض بسبب.

### المناطق والأسعار
من **لوحة الإدارة → المناطق والأسعار** تقدر تضيف منطقة جديدة،
وتغيّر أسعار البداية، وتضيف خطوط بين المناطق.

### لو حد نسي كلمة السر
من **لوحة الإدارة → الحسابات**، اضغط على علامة القفل جنب اسمه.
هتطلعلك كلمة سر مؤقتة، ابعتهاله وخليه يغيّرها من إعدادات حسابه.

---

## مشاكل شائعة

**«ملف config.php مش موجود»**
منسختش `config.example.php` باسم `config.php`. ارجع للخطوة ٣.

**«مقدرناش نوصل لقاعدة البيانات»**
اسم القاعدة أو المستخدم أو كلمة السر غلط. راجعهم من hPanel،
واوعى تنسى البادئة (`u123456789_`).

**«السيرفر ناقصه مكتبة الصور GD»**
من hPanel → **Advanced → PHP Configuration → PHP Extensions**،
فعّل `gd` و `exif`. لو مش لاقيها، كلّم الدعم — دي مكتبة أساسية وبيفعّلوها في دقايق.

**الصفحات بتدي 404 غير الرئيسية**
ملف `.htaccess` مترفعش (بيبقى مخفي). من File Manager:
**Settings → Show Hidden Files**، واتأكد إنه موجود جنب `index.php`.

**الصور مش بتترفع**
الصورة أكبر من ٨ ميجا، أو السيرفر محدّد `upload_max_filesize` أقل.
من PHP Configuration خلّيه `10M` على الأقل.

## نسخة احتياطية

كل حاجة في قاعدة البيانات — حتى الصور. فنسخة احتياطية واحدة بتاخد كل حاجة:

**hPanel → Databases → phpMyAdmin → Export → Go**

اعمل كده كل شهر، واحتفظ بالملف في مكان آمن.
