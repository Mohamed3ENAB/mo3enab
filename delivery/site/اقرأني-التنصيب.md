# في السكة — رفع الموقع على هوستنجر

ملف واحد تقراه وتخلص. **١٥ دقيقة.**

---

## اللي محتاجه

- دومين على هوستنجر (عندك)
- استضافة فيها **PHP 8.1 أو أحدث** و**MySQL** — أي خطة مشتركة فيها ده
- مفيش Node.js ولا أي حاجة تانية

---

## ١. اعمل قاعدة البيانات (٣ دقايق)

من **hPanel** ← **Databases** ← **MySQL Databases**:

1. اكتب اسم لقاعدة البيانات (مثلاً `sekka`)
2. اكتب اسم مستخدم وكلمة سر — **احفظهم**
3. اضغط **Create**

هوستنجر بتضيف بادئة للأسماء، يعني الاسم الحقيقي هيبقى زي `u123456789_sekka`.
**انسخ الأسماء زي ما هي ظاهرة في الصفحة.**

---

## ٢. ارفع الملفات (٥ دقايق)

من **hPanel** ← **Files** ← **File Manager**:

1. ادخل مجلد **`public_html`**
2. اضغط **Upload** وارفع ملف `سكة.zip`
3. اضغط كليك يمين على الملف ← **Extract** (فك الضغط)
4. امسح ملف الـ zip

> **مهم:** الملفات لازم تبقى **جوه `public_html` مباشرة** — يعني `index.php`
> يبقى في `public_html/index.php`، مش في `public_html/سكة/index.php`.
> لو اتفك جوه مجلد، ادخل المجلد واختار كل الملفات وانقلها لبرة.

---

## ٣. ظبط ملف الإعدادات (٣ دقايق)

في File Manager:

1. دوّر على **`config.example.php`**
2. كليك يمين ← **Rename** ← غيّر الاسم لـ **`config.php`**
3. كليك يمين ← **Edit** وحط القيم:

```php
'db_host' => 'localhost',
'db_name' => 'u123456789_sekka',      // من الخطوة ١
'db_user' => 'u123456789_sekka',      // من الخطوة ١
'db_pass' => 'كلمة السر بتاعتك',

'admin_password' => 'كلمة سر قوية',    // 🔴 غيّرها
'session_secret' => 'نص طويل عشوائي',  // 🔴 غيّرها — ٣٢ حرف أو أكتر
'support_phone'  => '01xxxxxxxxx',     // رقمك
'main_zone'      => 'القيصرية',
```

4. **Save**

> 💡 لتوليد `session_secret`: اكتب أي خليط طويل من حروف وأرقام، أو دوّر على
> «random string generator» واعمل واحد ٤٠ حرف.

---

## ٤. شغّل التنصيب (دقيقة)

افتح في المتصفح:

```
https://دومينك.com/install.php
```

سيب علامة «حط بيانات تجريبية» مفعّلة عشان تشوف الشكل، واضغط **ابدأ التنصيب**.

### 🔴 وبعدها على طول: امسح `install.php`

من File Manager: اختار `install.php` ← **Delete**.
سيبانه معناه إن أي حد يقدر يفتحه ويعيد التنصيب.

---

## ٥. خلاص، جرّبه

| الصفحة | اللينك |
|---|---|
| التطبيق | `https://دومينك.com` |
| لوحة الإدارة | `https://دومينك.com/admin` |

ادخل الإدارة بكلمة السر اللي حطيتها في `config.php`، **امسح البيانات التجريبية**،
وابدأ تضيف السواقين والمحلات الحقيقيين.

---

## تثبيته على الموبايل كتطبيق

**أندرويد (كروم):** هيظهرلك شريط «ثبّت التطبيق» لوحده. أو من القائمة ← «تثبيت التطبيق».

**آيفون (لازم سفاري):** زرار المشاركة ← **«إضافة إلى الشاشة الرئيسية»**.

هتلاقي الأيقونة على شاشتك، وبتفتح على طول من غير شريط المتصفح.

---

## حاجات مهمة

**لازم SSL (https).** من hPanel ← **SSL** ← فعّل الشهادة المجانية. من غيرها التثبيت
على الموبايل مش هيشتغل، والمتصفح هيقول «غير آمن».

**`.htaccess` موجود** وفيه إعدادات اللينكات النضيفة والحماية. لو اللينكات مشتغلتش
(كل حاجة بتوديك للصفحة الرئيسية)، اتأكد إن **mod_rewrite** مفعّل — هوستنجر مفعّلاه افتراضيًا.

**الصور متخزنة في قاعدة البيانات** مش في مجلد. يعني مفيش صلاحيات مجلدات تظبطها،
والنسخة الاحتياطية بتاعة قاعدة البيانات بتاخد الصور معاها.

---

## النسخ الاحتياطي

من hPanel ← **Databases** ← **phpMyAdmin** ← اختار قاعدة البيانات ← **Export** ← **Go**.
اعمل كده كل أسبوع في الأول.

---

## لو حصلت مشكلة

| المشكلة | الحل |
|---|---|
| «ملف config.php مش موجود» | غيّرت اسم `config.example.php`؟ |
| «مقدرناش نوصل لقاعدة البيانات» | راجع الأربع قيم في `config.php` — غالبًا البادئة `u123456789_` ناقصة |
| كل اللينكات بتوديني للرئيسية | `.htaccess` اترفع؟ (ملف مخفي — فعّل «Show hidden files» في File Manager) |
| الصور مش بتترفع | الاستضافة لازم يكون فيها **GD extension** — موجودة في كل خطط هوستنجر |
| التطبيق مش بيتثبّت على الموبايل | فعّل SSL (https) |

---

## تحديث الموقع بعدين

ارفع الملفات الجديدة فوق القديمة. **متمسحش `config.php`**، ومتشغّلش `install.php` تاني
(قاعدة البيانات موجودة خلاص).
